# v5指标框架

## 顶层唯一Owner

四个顶层分类互斥且完备：

1. 数值指标N：跨完整付费入口或组件的全局数值红线。
2. 中奖结算J：完整结算链中的实际派奖结果。
3. 玩法过程P：跨结算步骤的Feature周期和机制结果状态。
4. 盘面呈现B：稳定可见盘面的视觉符号构成、关键符号数量与空间结构。

归属冲突时按“结果属于J、过程属于P、静态画面属于B、全局红线属于N”处理。Cascade连续消除属于J3，不属于P。

## N：数值指标

N类固定六张硬门禁卡，逻辑保持独立，不参与J/P/B距离评价。

| ID | 指标 | 定义 |
|---|---|---|
| N1 | 总RTP | `sum(完整付费入口总派奖)/sum(实际经济投注)`；目标为用户确认的唯一数值 |
| N2 | 完整付费入口中奖率 | `P(return > 0)` |
| N3 | Feature自然触发率 | 每个Feature分别评价`P(自然进入Feature)` |
| N4 | 完整付费入口回报≥1x概率 | `P(return >= actual_entry_cost)`；Feature Buy按实际购买成本 |
| N5 | Sigma | 总体及画像要求的适用作用域作为卡内子项 |
| N6 | 组件RTP贡献 | Base、各Feature和其他组件作为卡内子项 |

N1目标必须由用户直接提供或明确确认，机器值必须位于`(0,1]`，禁止使用目标区间。资料只能提供候选值和核验证据；没有用户确认记录时不得生成指标合同。N6逐组件目标使用原版组件贡献占比乘以该用户确认总RTP得到。

N4边界包含1x，容差系数固定1.5。原付费入口倍率分布、200x以上长尾、最大中奖和封顶只作审计。

## J：中奖结算

### J1 中奖构成

逐组件冻结2～5个玩家可识别、互斥且完整覆盖该组件派奖元素的中奖组，评价：

```text
P(中奖组参与 | 当前组件发生正派奖步骤)
```

优先使用主题或最高价值组、其他高价值组、低价值组，以及确实独立可感知的特殊奖励组。同一步可以有多个中奖组参与，各组概率不要求合计为1。只有一个派奖元素的组件不生成J1；逐普通元素、逐Payline和条件必然为100%的参与率不生成指标。

### J2 中奖规模

正式Facet：

- 主要中奖结构规模：每个`组件 × 结算模型`最多保留一个玩家最容易识别且存在多个可达值的主轴。Payline为连中轴数，Ways为实际中奖Ways，Count Pay为实际派奖符号数，Cluster为中奖连片格数，全屏消除为实际消除格数，其他模型由画像冻结唯一自定义主轴。
- 同步可见中奖结果数量：仅在该数量存在多个可达值时，逐组件评价一个正派奖步骤中玩家看到的独立中奖结果数。
- 单步可见奖励大小：仅在正派奖步骤奖励存在多个可达值时，逐组件评价`sum(当前正派奖步骤奖励) / 玩家界面展示投注基准`。

连中轴数、逐元素结构、逐线路结构及同一结算模型的第二结构轴不生成指标。Base、各Feature和其他玩家可区分组件不得合并；Feature Buy购买成本不作为J类奖励分母。

### J3 连续结算

正式Facet：

- 连续结算总深度分布；未进入连续结算记为0，只有多个可达深度时才生成。
- 整条连续结算奖励大小：对已开始的连续结算链评价`sum(整链可见奖励) / 玩家界面展示投注基准`，只有多个可达奖励值时才生成。

逐深度reels、Ways、结构规模、继续概率和各层RTP贡献均不生成指标，也不转为审计。每个连续结算作用域只生成总深度和整链奖励两个正式实例。

## P：玩法过程

### P1 周期节奏

正式Facet：

- 初始免费旋转次数分布，仅Free Spin适用。
- 完整Feature持续长度分布，以玩家实际经历的主要动作数表达：Free Spin为总旋转数；Hold & Spin/Respin为总重转步骤；抽取玩法为总抽取或阶段数。

重触发、续命、延长、Reset、Add和Replace不独立评价，只用于诊断完整持续长度差异。

### P2 机制结果状态

每种画像命中的特色机制建立一个卡内子项；每个合格机会必须进入一个互斥、完备的规范结果状态，并包含`未发生`或`未生效`。

Buffalo Wild倍数可表达为：未出现、出现但未生效、实际生效2x、实际生效3x及其他实际倍数。Wild数量和位置属于B；倍数影响后的奖励大小属于J2；增量RTP只作审计。

## B：盘面呈现

只统计玩家实际看到的稳定盘面，不统计动画临时帧。

### 正式盘面作用域

每个组件最多冻结两类正式盘面：

- `initial`：一次主要动作的初始落盘。
- `cascade_visible`：发生连续结算后玩家看到的补位稳定盘，包括最后一次无新中奖的补位终盘；未发生连续结算时，不把initial再次记录为terminal。

Base与Feature分别实例化；`initial`与`cascade_visible`不得合并平均。原始terminal、具体cascade层级和其他阶段盘面可以保留在A5审计，但不重复生成正式B实例。

### B1 可见符号构成

- 普通符号按画像冻结的视觉符号组评价单盘有效格密度：`count(group_symbols) / count(active_visible_cells)`。符号组必须互斥，不得与关键计数符号重叠。
- 视觉符号组优先表达玩家能直接区分的层级：主题标志普通符号、其他高价值普通符号、低价值普通符号。通常每个盘面使用2～5组；不得为追逐候选结果事后拆组或并组。
- Wild、Scatter/Bonus、Collector等关键特殊符号评价单盘绝对数量分布，必须包含0；这些符号由画像的`key_symbols`冻结。
- 每个正式盘面的`symbol_groups + key_symbols`必须互斥且完整覆盖可见符号域，避免指标盲区。

视觉组占比、关键符号出现率由正式分布派生，只展示，不重复评价。

### B2 盘面空间结构

正式Facet：

- 盘面形态：可变轴高、有效格区域或等价可见形状；固定盘面只作规则审计。
- 关键符号空间位置：只对画像预先选定的核心特殊符号，比较其在可见格中的位置密度。

关键空间符号通常包括玩家会主动寻找的Wild、Scatter/Bonus、Collector或具有位置机制的特殊符号，并且必须来自当前盘面的`key_symbols`。普通付费符号默认不进入B2；只有原版证据证明其存在独立的分区、堆叠、固定轴或其他空间规则时，才同时升格为关键符号并纳入。选择结果及证据必须随玩法画像在候选出现前冻结。

位置密度只统计符号出现的稳定盘面。每个盘面总质量固定为1，并在该盘全部同符号格之间均分，再聚合到规范可见格。因此关键符号数量和出现率仍由B1唯一评价，B2只评价位置倾向，不按精确数量生成子项，也不评价所有普通符号的完整占位图。

每个可变正式盘面作用域生成1个盘面形态实例；每个画像选定的关键空间符号在对应正式盘面作用域生成1个位置实例。

Buffalo推荐冻结Base/Free各自的`initial`与`cascade_visible`共4个盘面，每盘3个视觉普通符号组、WILD/BONUS两个关键数量、1个盘面形态和2个关键位置，共`4 * (3 + 2 + 1 + 2) = 32`个B实例。

## 卡内子项规则

- 中奖组、组件、结算模型、Feature、机制、符号和盘面作用域只按本框架规定扩展卡内子项，不产生权重。
- 每个命中子项都必须评价，卡状态取最差子项。
- 玩法画像证明机制不存在时才可不实例化；实例化后不得豁免。
- 固定、条件必然、单一可达或由其他正式指标确定性覆盖的J细项直接不生成；其他分类只有政策明确要求时才保留独立规则审计。

# v5指标框架

## 顶层唯一Owner

四个顶层分类互斥且完备：

1. 数值指标N：跨完整付费入口或组件的全局数值红线。
2. 中奖结算J：完整结算链中的实际派奖结果。
3. 玩法过程P：跨结算步骤的Feature周期和机制结果状态。
4. 盘面呈现B：稳定可见盘面的符号数量与空间结构。

归属冲突时按“结果属于J、过程属于P、静态画面属于B、全局红线属于N”处理。Cascade连续消除属于J3，不属于P。

## N：数值指标

N类固定六张硬门禁卡，逻辑保持独立，不参与J/P/B距离评价。

| ID | 指标 | 定义 |
|---|---|---|
| N1 | 总RTP | `sum(完整付费入口总派奖)/sum(实际经济投注)`；目标为用户确认的唯一数值 |
| N2 | 完整付费入口中奖率 | `P(return > 0)` |
| N3 | Feature自然触发率 | 每个Feature分别评价`P(自然进入Feature)` |
| N4 | 完整付费入口回报≥1x概率 | `P(return >= actual_entry_cost)`；Feature Buy按实际购买成本 |
| N5 | Sigma | 总体及画像要求的适用作用域作为卡内子项 |
| N6 | 组件RTP贡献 | Base、各Feature和其他组件作为卡内子项 |

N1目标必须由用户直接提供或明确确认，机器值必须位于`(0,1]`，禁止使用目标区间。资料只能提供候选值和核验证据；没有用户确认记录时不得生成指标合同。N6逐组件目标使用原版组件贡献占比乘以该用户确认总RTP得到。

N4边界包含1x，容差系数固定1.5。原付费入口倍率分布、200x以上长尾、最大中奖和封顶只作审计。

## J：中奖结算

### J1 中奖构成

正式子项：

- 每个规范结算元素的中奖参与率：`P(元素参与 | 正派奖结算步骤)`。
- 固定线游戏每条规范线路的中奖参与率：`P(线路参与 | 正派奖结算步骤)`。

同一步可由多个元素或线路参与，各子项是独立概率，不要求合计为1。元素和线路的绝对RTP贡献、结算RTP占比只作审计与守恒复核。

### J2 中奖规模

正式Facet：

- 单个中奖结果规模：Payline为连中轴数；Ways为连中轴数和实际中奖Ways；Count Pay为实际派奖符号数；Cluster为中奖连片格数；全屏消除为实际消除格数。
- 正派奖步骤中的同步中奖结果数量。
- 实际奖励大小：只有元素和结构规模不能唯一确定派奖时启用；固定赔付映射时确定性派生并只展示。

### J3 连续结算

正式Facet：

- 连续结算总深度分布；未进入连续结算记为0。
- 指定结算层级下的J2中奖规模分布。

继续概率由深度分布派生，各层RTP贡献只作审计。

## P：玩法过程

### P1 周期节奏

正式Facet：

- 初始免费旋转次数分布，仅Free Spin适用。
- 完整Feature持续长度分布，以玩家实际经历的主要动作数表达：Free Spin为总旋转数；Hold & Spin/Respin为总重转步骤；抽取玩法为总抽取或阶段数。

重触发、续命、延长、Reset、Add和Replace不独立评价，只用于诊断完整持续长度差异。

### P2 机制结果状态

每种画像命中的特色机制建立一个卡内子项；每个合格机会必须进入一个互斥、完备的规范结果状态，并包含`未发生`或`未生效`。

Buffalo Wild倍数可表达为：未出现、出现但未生效、实际生效2x、实际生效3x及其他实际倍数。Wild数量和位置属于B；倍数影响后的奖励大小属于J2；增量RTP只作审计。

## B：盘面呈现

只统计玩家实际看到的稳定盘面，不统计动画临时帧。

### B1 符号呈现

每个符号评价单盘数量分布，必须包含0。普通符号、Wild、Scatter采用同一规则；Base、Feature和必要盘面阶段作为卡内作用域。

符号出现概率由`P(count >= 1)`派生，只展示，不重复评价。

### B2 盘面空间结构

正式Facet：

- 盘面形态：可变轴高、有效格区域或等价可见形状；固定盘面只作规则审计。
- 关键符号空间位置：只对画像预先选定的核心特殊符号，比较其在可见格中的位置密度。

关键空间符号通常包括玩家会主动寻找的Wild、Scatter/Bonus、Collector或具有位置机制的特殊符号。普通付费符号默认不进入B2；只有原版证据证明其存在独立的分区、堆叠、固定轴或其他空间规则时才纳入。选择结果及证据必须随玩法画像在候选出现前冻结。

位置密度只统计符号出现的稳定盘面。每个盘面总质量固定为1，并在该盘全部同符号格之间均分，再聚合到规范可见格。因此符号数量和出现率仍由B1唯一评价，B2只评价位置倾向，不按精确数量生成子项，也不评价所有普通符号的完整占位图。

每个可变盘面作用域生成1个盘面形态实例；每个画像选定的关键空间符号在对应盘面作用域生成1个位置实例。Buffalo六个盘面作用域选择WILD和BONUS时，B2共生成`6 + 6*2 = 18`个实例。

## 卡内子项规则

- 元素、符号、Feature、机制、线路、层级和作用域只扩展卡内子项，不产生权重。
- 每个命中子项都必须评价，卡状态取最差子项。
- 玩法画像证明机制不存在时才可不实例化；实例化后不得豁免。
- 固定、单一可达结果转为规则审计，不生成常量通过项。

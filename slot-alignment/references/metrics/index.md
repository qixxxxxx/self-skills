# 指标库索引

Core 对所有游戏必加载；Atomic 对单一玩法能力；Composite 对完整玩法周期；Interaction 只衡量跨玩法新增联合体验。每个`metric_id`只有一个 Owner。

| 类型 | 包 | 适用画像 |
|---|---|---|
| Core | core.general | 全部游戏 |
| Atomic | atomic.free-spin | feature.free-spin |
| Atomic | atomic.respin | feature.respin |
| Atomic | atomic.cascade | evolution.cascade |
| Atomic | atomic.modifier | Wild/倍率修饰 |
| Composite | composite.feature-cycle | 免费旋转或重转完整周期 |
| Interaction | interaction.cascade-multiplier | Cascade 与倍率联合 |

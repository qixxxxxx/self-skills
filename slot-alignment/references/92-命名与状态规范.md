# 命名与状态规范

## 固定目录

```text
artifacts/
├── 01-input-profile/
├── 02-metric-matching/
├── 03-scoring/          # scorecard.json、阶段3-评分报告.md、stage3_gate.json
├── 04-alignment/
└── 05-delivery/
```

机器文件使用稳定英文 snake_case；人类 Markdown 使用固定中文名。状态只使用：`未开始`、`进行中`、`已完成`、`阻塞`、`不适用`、`缺口`、`通过`、`豁免后通过`、`不通过`、`无法判定`、`硬指标已豁免`、`审计`。

稳定 ID 使用小写字母、数字、点和连字符；同一语义不得改名复用。版本使用`v####`，交付版本使用`dv####`。所有时间使用带时区 ISO 8601，所有概率使用 0～1，小数 RTP 使用 0～1；报告可另行显示百分比。

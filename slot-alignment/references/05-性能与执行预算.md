# 7.0 样本、性能与续跑

本文件只规定候选和FORMAL如何取样、聚合及续跑。候选和FORMAL始终使用用户认证脚本的同一模拟核心。

## 一、样本计划

样本计划在开工时由用户确认并写入`preflight.json.sample_plan`。默认建议：

| 阶段 | 累计完整付费入口 | 用途 |
|---|---:|---|
| PROBE | 20000 | 判断参数方向，不作通过结论 |
| SCREEN | 100000 | 全部有效候选初筛 |
| REFINE | 500000 | 前列候选复筛 |
| FINAL | 2000000 | 最终候选排序 |

PROBE可关闭。SCREEN、REFINE和FINAL允许按开工时冻结的晋级规则提前停止，不要求每个参数层完整跑满。

候选默认每批生成100组。每批大小只控制单轮计算量，不限制任务累计候选数；没有候选通过FORMAL时继续生成下一批不重复候选。

FORMAL默认档位为`10000000/20000000/50000000`，目标为每个活动条件实例至少2000个有效样本。用户也可以在开工时明确确认其他正式样本数；一旦合同冻结不得运行中修改。

## 二、候选晋级

候选按以下元组升序排序：

```text
(
  N类失败数,
  J/P/B失败数,
  样本不足或计算异常数,
  最大偏差倍数,
  偏差倍数总和,
  candidate_id
)
```

提前停止只允许使用冻结规则：

- 明显被其他候选完全支配；
- 当前层连续若干候选没有减少失败项且改善低于冻结下限时，切换搜索方向或参数面；
- 已出现全部活动指标通过且排名稳定的候选；
- 当前参数面穷尽，需要升级到其他已授权Runtime参数；

不得因为单次随机结果不好拒绝候选、回滚或换seed。

候选搜索不设固定总数上限。每批结束后，如果没有候选进入FORMAL或FORMAL没有通过，就根据敏感性、失败指标和已覆盖参数区域生成下一批。新候选的参数hash不得与账本中已有记录重复。

“授权参数空间穷尽”必须有可复核证据：全部离散组合已经覆盖，或连续参数在开工时冻结的边界和最小步长下已经覆盖。候选数量很多、运行时间较长或连续若干批改善很小，都不能单独作为穷尽依据。

## 三、同一脚本保证

候选和FORMAL记录相同的：

```text
certified_script_sha256
adapter_sha256
metric_contract_sha256
runtime_bundle_sha256
```

认证脚本负责随机与玩法语义；adapter只负责传参、观测和聚合。若adapter改变随机调用或游戏状态，则视为新的认证脚本，必须由用户重新确认。

## 四、聚合

正式执行使用有界累计器：

| 类型 | 累计内容 |
|---|---|
| 概率和比例 | 成功次数、有效分母 |
| RTP | 投注总额、派奖总额 |
| Sigma | count、sum、sum_square或稳定在线算法 |
| 固定分布 | 冻结支持对应的整数计数数组 |
| mean | count和sum |
| P50/P90 | 冻结有界支持或固定直方图 |

禁止在大样本热路径保存全量逐入口JSON、为每次随机创建新RNG对象、逐入口计算hash或维护无界精确赢分字典。

## 五、checkpoint与续跑

- checkpoint按固定入口区间保存累计器、seed、Runtime hash、脚本hash和合同hash。
- 续跑时全部指纹一致才允许跳过已完成区间。
- checkpoint大小和频率可以调整，不属于业务合同。
- 合并顺序按入口区间起点升序。
- 普通短候选可以只有一个最终汇总，不强制建立分片文件。

## 六、并行

并行只是性能手段，不是正式门禁：

- 默认最多使用逻辑CPU的70%，为系统保留资源；
- 同一执行只使用一层主并行；
- Worker加载一次Runtime和认证脚本上下文；
- Worker数和micro-batch变化不能改变seed映射；
- 不再强制生成单Worker、多Worker、不同micro-batch和中断续跑的完整等价报告。

发现并行结果不稳定时回退单Worker并记录，不因此阻止其他候选生成。

## 七、FORMAL

FORMAL使用唯一候选和独立seed，重新运行全部活动指标。它不复用候选测量，也不需要额外的前2名独立复核。

每次FORMAL尝试使用开工时冻结的确定性seed序列中新的一段，保证与候选测量及其他FORMAL尝试独立。seed按FORMAL尝试序号分配，不能根据运行结果选择。

FORMAL失败后，把候选和本次seed记录为已使用，返回候选搜索并创建新的Runtime候选和FORMAL运行记录；禁止同一候选仅更换seed重试。搜索持续到FORMAL通过、授权参数空间穷尽、用户主动停止或技术故障。

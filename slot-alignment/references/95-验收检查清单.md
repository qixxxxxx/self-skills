- [ ] 付费入口链、金额守恒、自然/定向样本分流正确。
- [ ] 脚本与 server 当前版本一致，观测增强未改变逻辑。
- [ ] 必需玩法语义有唯一 Owner；玩法覆盖率 100%。
- [ ] Core 与专项必需指标完整；指标可测率 100%。
- [ ] 评价合同、基础容差、容差系数、生效容差、政策 hash、权重、样本资格和边界在看候选前密封。
- [ ] 权威总 RTP 系数为 1.0 且未扩大目标区间；旧任务未回溯套用新政策。
- [ ] 配置异常已排除；不可达结论有结构证据。
- [ ] 所有豁免均由用户批准且 hash 仍有效。
- [ ] 只修改授权数值参数；候选合法且已冻结。
- [ ] FORMAL 种子与样本独立，尝试次数符合密封计划。
- [ ] 机器评分可复算；Markdown 与 JSON 一致。
- [ ] 200x 以上、最大中奖、封顶和溢出均完成审计。
- [ ] 交付 manifest 的路径与 SHA-256 全部有效。

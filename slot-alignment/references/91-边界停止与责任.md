# 边界、停止与责任

## AI 自动负责

资料检查、协议归一化、玩法画像、指标匹配、缺口汇总、可达性预检、评分、授权范围内调参、CALIBRATION、FORMAL、报告和交付校验。

## 用户唯一负责

提供或确认无法自动唯一解析的路径/目标/作用域；批准指标库扩展；批准或撤销指标豁免；授权扩大参数范围或执行外部同步、发布操作。

## 不可自动越过

- 无法证明脚本与 server 一致。
- 需要改变玩法规则才能达标。
- 必需数据缺失、样本资格不成立或目标来源不权威。
- 必需指标缺口未批准。
- 配置异常尚未修复。
- 参数授权不足或作用域冲突。
- 授权空间已密封为结构不可达；在扩权、目标/合同批准变化或原证据失效前，不得继续单纯追加预算。

发现阶段4已开始但阶段3固定产物或转换门禁缺失时，自动停止新增候选并退回阶段3。若合格基线测量和已密封合同仍有效，直接确定性补齐评分、报告和门禁，不需要用户批准；若基线测量或合同资格失效，则按缺失原因停止询问。

临时错误用同一密封输入自动重试 2 次。仍失败时保存错误、命令、输入 hash、已完成阶段和最小恢复动作，再向用户提出一个问题。

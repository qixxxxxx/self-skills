# 交付后Server Flow验证报告

> 本报告位于不可变交付包之外，只做单次Server Flow硬指标对照；任何结果都不改变阶段1至5、FORMAL、候选或交付状态。

## 一、审计结论与状态隔离

- 展示方式：三列表格后接警告块。
- 必需字段：项目、结果、含义
- 空值规则：执行失败、异常、绑定失效、样本不足、密封硬指标缺失、对照结果为空或任一硬指标不一致时结论写“警告”；既有状态影响始终写“无”。
- 展示实例：
```markdown
| 项目 | 结果 | 含义 |
|---|---|---|
| 审计结论 | 警告 | 仅供排查 |
| 既有状态影响 | 无 | 不回写FORMAL或交付 |
```

## 二、交付版本与输入绑定

- 展示方式：三列表格，一项绑定一行。
- 必需字段：对象、值、校验
- 空值规则：交付版本、manifest hash或Server/Runtime/候选/FORMAL/scorecard hash缺失时记录警告，不回退交付。
- 展示实例：
```markdown
| 对象 | 值 | 校验 |
|---|---|---|
| 交付版本 | dv0001 | 只读绑定 |
```

## 三、硬指标数值对照

- 展示方式：八列表格，一项硬指标一行。
- 必需字段：指标、作用域、FORMAL、Server Flow、差距、容差、样本资格、对照状态
- 空值规则：无结果或不可比时保留行并写“警告/无法对照”。
- 展示实例：
```markdown
| 指标 | 作用域 | FORMAL | Server Flow | 差距 | 容差 | 样本资格 | 对照状态 |
|---|---|---|---|---|---|---|---|
| 总RTP | paid-entry | 0.96 | 0.958 | 0.002 | 0.003 | 有效 | 一致 |
```

## 四、异常与警告

- 展示方式：三列表格，一项警告一行。
- 必需字段：类型、内容、处置
- 空值规则：无警告时保留表头并写“无”；有警告时处置固定为“仅记录，不改变既有状态”。
- 展示实例：
```markdown
| 类型 | 内容 | 处置 |
|---|---|---|
| RTP差异 | 超出生效容差 | 仅记录，不改变既有状态 |
```

## 五、不可变性声明

- 展示方式：三列表格，一项隔离规则一行。
- 必需字段：对象、结果、规则
- 空值规则：任何对象都不得显示已回写或已失效。
- 展示实例：
```markdown
| 对象 | 结果 | 规则 |
|---|---|---|
| FORMAL | 保持原状态 | 审计不参与状态传播 |
```
